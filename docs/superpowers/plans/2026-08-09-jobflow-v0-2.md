# JobFlow v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring JobFlow's public schema, local scripts, and reports in line with the real workflow while keeping private job-search data outside the repository.

**Architecture:** Keep JSONL as the portable storage format. Add a small normalization layer that maps platform and status aliases to canonical values, introduce explicit contact timestamps and stable IDs for new records, and preserve unknown fields during migration. Make reporting and target checks consume normalized records and keep migration as an explicit user-invoked command.

**Tech Stack:** Python 3.10+, standard library only, `unittest`, GitHub Actions, Markdown documentation.
